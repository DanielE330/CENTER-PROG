## Сверка с проектом

| # | Требование | Что есть | Разрыв / что делать |
|---|---|---|---|
| 1 | Предприниматель в центре | Одна компания на пользователя, русский интерфейс, регистрация с названием юрлица, вход по ЭЦП | Проверить формулировки UI на «язык предпринимателя» (без терминов вроде bootstrap, p90) |
| 2 | Формат | Отдельный сервис | Ок. В защите проговорить, что его можно встроить в ЦИ (API + SPA разделены) |
| 3 | Ссылка для жюри | Только локальный запуск (`infra/scripts/dev.sh`); Docker-сборка не проверялась | **Главный пробел.** Развернуть на публичном адресе (HTTPS, `COOKIE_SECURE=true`), проверить `docker compose` до защиты |
| 4 | Аргументация выбора | `docs/architecture.md`, `docs/forecast_evaluation.md` (сравнение методов) | Добавить в презентацию 1 слайд «почему Rust + SQLite + Python-сервисы» |
| 5 | Полностью рабочие фичи | Обязательный минимум закрыт; вероятность разрыва плохо откалибрована (`knowledge-base.md` §9) | Калибровка — слабое место минимума: поднять порог до 0.9 как рабочую точку и честно показать precision/recall |
| 6 | Ручной ввод «квитанций» | Ожидаемые события вручную, ЕНП по сумме | Ок |
| 7 | Автоподгрузка налогов и граничные случаи | Новый модуль `backend/services/gov/`: налоговый календарь ФНС, ключевая ставка ЦБ, производственный календарь, взносы | Модуль **не подключён к API**: события налогового календаря не попадают в `expected-events`. Подключить: кнопка «подтянуть сроки» → события. Нет УСН-авансов и НДС (в `knowledge-base.md`) |
| 8 | Интеграции отдельными сервисами | Файл + ручной ввод + парсер госсайтов (реальные данные) | Нет имитации 1С / ЭДО / банка. Сделать маленький сервис-имитатор (например, 1С: договоры и счета JSON/HTTP) и подгрузку через общий импорт |
| 9 | Контрольный датасет и новое событие | Импорт CSV/XLSX формата датасета, ручное ожидаемое событие, пересчёт целиком, прогноз помечается `stale` | Проверить на «чужой» выписке из того же формата; после добавления события прогноз пересчитывается только вручную (кнопкой) — сделать авто-пересчёт, чтобы реакция была видна сразу |
| 10 | Чек-поинты | — | Подготовить демо: загрузка выписки → прогноз → риск разрыва → новое событие → реакция → сценарий |
