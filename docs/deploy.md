# Публикация сервиса (ссылка для жюри)

Стек целиком поднимается через `make -C infra up` (Docker Compose) и отдаёт SPA и API на порту `3000` шлюза Caddy.
Чтобы получить публичный адрес, достаточно проксировать домен на хост со стеком через уже работающий edge-Caddy домашней
инфраструктуры (описана в личной базе знаний сервера, не в репозитории):

1. Запустить стек на хосте: `make -C infra up`, затем `make -C infra seed` (демо-данные для `demo@example.com`).
2. На edge-Caddy добавить блок домена с `reverse_proxy <адрес-хоста>:3000` и перезагрузить конфиг (`caddy reload`);
   Let's Encrypt выпустит сертификат сам.
3. Включить `COOKIE_SECURE=true` (HTTPS) в окружении compose, иначе cookie сессии не будет защищена.
4. Для входа по ЭЦП на публичном домене добавить его в `/etc/opt/cprocsp/trusted_sites.html` на машине пользователя.

Логины, пароли и ключи в репозиторий не кладём; значения берутся из окружения или менеджера паролей.
