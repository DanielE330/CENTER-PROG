# CenterInvest: подготовленная среда

Инструкции по установленным инструментам: docs/TOOLING.md.

- Backend: Rust. ML: Python/PyTorch. Frontend: React/TypeScript.
- Python и ML-библиотеки: `.venv/bin/python`; активировать `.venv` или использовать явный путь.
- Frontend-toolchain: `.tooling/frontend`, команды через `pnpm --dir .tooling/frontend exec ...`.
- Проектные скиллы: `.claude/skills/`. Перед профильной задачей читай соответствующий SKILL.md и необходимые references.
- Настройка инструментов не означает, что архитектура, CI/CD или приложение уже реализованы.
- Не делай push, deploy, изменение работающих сервисов и удаление данных без отдельного разрешения.
- Проверки запускай реально; недоступную или пропущенную проверку не называй успешной.
