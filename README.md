# ЦИ1 — прогноз денежного потока для малого бизнеса

Кейс «Центр-инвест», хакатон ДГТУ, осень 2026. Сервис разбирает банковскую выписку, прогнозирует остаток по дням, находит кассовые разрывы (дата, сумма, вероятность, причины) и подсказывает, что делать.

## Данные

Датасет организаторов в git не хранится. Положите распакованный архив в `data/` и сверьте контрольные суммы:

```bash
cd data && sha256sum -c MANIFEST
```
